Query input stays generic so each **driver** keeps its native shape. PostgreSQL takes SQL. Firestore takes collection queries. Hosted providers (Supabase) set their own `id` and reuse a driver. The core does not translate one into the other.

<AutoTypeTable path="packages/core/src/provider.ts" name="DatabaseProvider" />

Hosts pass a provider instance into [`connect()`](/docs/api/connect). Driver packages export factories such as `postgres()` and `firestore()`. Hosted providers export factories such as `supabase()`.

`query()` is read-only and fail-closed. SDK checks are extra; a read-only database role is the security boundary.
